# Corner Grocer Item-Tracking System

[cite_start]An interactive C++ application built for the Corner Grocer to analyze and track daily produce purchase frequencies[cite: 7, 8]. [cite_start]The program processes chronological transaction logs to generate alphabetized frequency ledgers and visual text-based histograms, aiding store management in optimizing product placement[cite: 8, 9, 14].

## Features
* [cite_start]**Automatic Data Backup:** On initialization, the system automatically aggregates raw data and writes a consolidated backup file named `frequency.dat`[cite: 34, 35].
* [cite_start]**Individual Item Search:** Allows managers to securely query the transactional frequency of any specific product[cite: 25, 26].
* [cite_start]**Alphabetized Frequency Report:** Displays a cleanly aligned, tabular list of all unique grocery inventory items sorted alphabetically[cite: 14, 30].
* [cite_start]**Text-Based Histogram:** Dynamically renders an asterisk-based (`*`) visual bar graph representing individual item sales velocity[cite: 32].
* [cite_start]**Input Validation:** Protects system memory and execution loops against invalid user menu entries[cite: 23].

## Architecture & Constraints
* [cite_start]**Data Structure:** Leverages `std::map<std::string, int>` for $O(\log n)$ algorithmic lookup efficiency and automatic alphabetical sorting[cite: 12, 16].
* [cite_start]**Stream Safety:** Implements fixed-width character arrays (`char[]`) during file parsing to preserve stream pointers and prevent line-skipping glitches[cite: 19, 20].
* [cite_start]**Memory Management:** Utilizes safe stack memory management strategies to guarantee a 0% risk of runtime memory leaks or segmentation faults[cite: 21, 22].

## File Structure
* `main.cpp` - Coordinates user interface loop, input handling, and program branching.
* `ItemTracker.h` - Declares the core `ItemTracker` tracking class and its operational documentation.
* `ItemTracker.cpp` - Implements robust character-array file I/O operations and report rendering logic.
* [cite_start]`CS210_Project_Three_Input_File.txt` - Raw input transaction data log file[cite: 35].
* [cite_start]`frequency.dat` - Consolidated backup data file automatically generated by the application[cite: 33, 35].
