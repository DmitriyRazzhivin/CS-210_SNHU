# Corner Grocer Item-Tracking System

An interactive C++ application built for the Corner Grocer to analyze and track daily produce purchase frequencies. The program processes chronological transaction logs to generate alphabetized frequency ledgers and visual text-based histograms, aiding store management in optimizing product placement.

## Features
* **Automatic Data Backup:** On initialization, the system automatically aggregates raw data and writes a consolidated backup file named `frequency.dat`.
* **Individual Item Search:** Allows managers to securely query the transactional frequency of any specific product.
* **Alphabetized Frequency Report:** Displays a cleanly aligned, tabular list of all unique grocery inventory items sorted alphabetically.
* **Text-Based Histogram:** Dynamically renders an asterisk-based (`*`) visual bar graph representing individual item sales velocity.
* **Input Validation:** Protects system memory and execution loops against invalid user menu entries.

## Architecture & Constraints
* **Data Structure:** Leverages `std::map<std::string, int>` for $O(\log n)$ algorithmic lookup efficiency and automatic alphabetical sorting.
* **Stream Safety:** Implements fixed-width character arrays (`char[]`) during file parsing to preserve stream pointers and prevent line-skipping glitches.
* **Memory Management:** Utilizes safe stack memory management strategies to guarantee a 0% risk of runtime memory leaks or segmentation faults.

## File Structure
* `main.cpp` - Coordinates user interface loop, input handling, and program branching.
* `ItemTracker.h` - Declares the core `ItemTracker` tracking class and its operational documentation.
* `ItemTracker.cpp` - Implements robust character-array file I/O operations and report rendering logic.
* `CS210_Project_Three_Input_File.txt` - Raw input transaction data log file.
* `frequency.dat` - Consolidated backup data file automatically generated by the application.
