# CS-210: Programming Languages (C++)

A repository dedicated to projects, labs, and assignments completed during the CS-210 course. This course focuses on fundamental programming concepts, object-oriented design, and efficient memory management using **C++**.

## 📌 Repository Structure

* `Project_1/` — Chada Tech Clock Application (Console UI)
* `Project_2/` — Airgead Banking Investment Calculator (Financial Logic)
* `Assignments/` — Weekly coding challenges and concept implementations

---

## 🚀 Key Projects

### 1. Chada Tech Clock Application
* **Description:** A dual-clock system displaying both 12-hour and 24-hour formats simultaneously, allowing real-time simulated user adjustments via a console menu.
* **Core Concepts:** Input validation, formatted console output, and functional modularity.

### 2. Airgead Banking Investment Calculator
* **Description:** A financial analysis tool that models investment growth over time, comparing year-end balances and accrued interest both with and without additional monthly deposits.
* **Core Concepts:** Object-Oriented Programming (OOP), robust class structures, iterative math formatting, and data presentation.

---

## 🛠️ Concepts & Skills Covered

* **Object-Oriented Programming:** Designing clean, maintainable code using classes, encapsulation, and clear separation of concerns (`.h` headers vs. `.cpp` implementations).
* **Memory Management:** Understanding pointers, references, and fundamental C++ memory layout.
* **Defensive Programming:** Writing strict input validation to handle edge cases and prevent execution errors.
